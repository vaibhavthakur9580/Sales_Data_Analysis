Power BI Project 1: Sales Data Dashboard


📊 Project Overview

    This Power BI project focuses on building a dynamic sales dashboard using real-world sales data. 
    
    It provides actionable insights into sales performance, profit trends, customer segments, and regional performance.


🛠 Tools & Technologies

    Power BI Desktop
    
    DAX (Data Analysis Expressions)
    
    Power Query
    
    Data Modeling & Relationships

    
📌 Key Features

    Sales by region, category, and sub-category
    
    Profitability analysis by segment
    
    Dynamic slicers for Year, Region, and Category
    
    Top N customers and products visualization
    
    Interactive bar, pie, and stacked column charts

📁 Files Included

📈 Outcome

    The dashboard allows business users to easily monitor KPIs and drill down into key areas such as customer profitability, top-selling products, and regional trends.
